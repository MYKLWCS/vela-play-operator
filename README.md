# VELA — play-money white-label operator

Demo only. No real-money wagering. Built so you can press the same surfaces NuxGame sells, plus poker and lotto, on one wallet.

Open `index.html` or deploy the repo as a static site.

## What works

- Lobby, originals (dice, mines, plinko, crash, roulette, blackjack)
- Video poker + heads-up hold'em
- Daily lotto 6/49
- Sportsbook slip + settle
- Prediction markets
- Cashier (cash + bonus), ledger, VIP wheel
- Vendor adapter table
- Affiliates / agents
- Back office skin + game flags
- Open-source stack map

## White label

Change `BRAND` and back-office name. Add a vendor by appending to `VENDORS` and implementing the seamless-wallet endpoints later. Do not fork the lobby for each studio.

## Not included (on purpose)

Pragmatic / Evolution catalogs, Genius live odds, Corefy rails, and a gambling licence. Those are contracts, not GitHub clones.
